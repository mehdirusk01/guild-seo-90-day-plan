# Guild Garage Group: 90-Day Local SEO Plan

A one-page proposal for the **SEO Manager** role at Guild Garage Group, built during the MBA Career Lab ("Stand out with AI": decode the job post, name the hidden problem, build a solution, package it).

## The hidden problem

> Guild needs its ~30 local garage door brands to generate more low-cost booked jobs from search, but each brand's SEO, Google profiles and reviews were built separately before joining Guild, so they're hiring someone to set one local SEO standard and turn visibility into booked jobs.

## The plan in short

1. **Days 1–30 · Audit and baseline:** audit every brand, Local SEO Standard v1, agency scorecard.
2. **Days 31–60 · Fix the top 5 brands:** Brand Priority Score, standard applied, review requests live.
3. **Days 61–90 · Scale and prove:** rollout plan, checklist for every new acquisition, first scorecard.

## Method

Built with AI (research, drafting, critique), then every fact checked against its source. Sources are listed at the bottom of the website. Independent proposal based on public information only; not affiliated with Guild Garage Group.
